Exo editor plugin

Polyfork for Exo

A left side-bar browser for the free Polyfork low-poly catalogue. Filter by name or full asset id, category and kit; 20 assets per page; missing thumbnails are rendered from the parametric three.js module. 

{
  "schemaVersion": 1,
  "plugins": [
    {
      "manifest": "https://mode777.github.io/exo-polyfork/exo-manifest.json",
      "enabled": true
    }
  ]
}

Source and setup Open Exo Polyfork Manifest

The plugin is served from the same origin as the Exo shell, so Exo runs it in an opaque sandbox. Rendered thumbnails cache for the session; official thumbnails use the normal HTTP cache. The source prefers IndexedDB on a cross-origin host.
